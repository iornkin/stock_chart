# 데이터 제공처: 이용 조건과 호출 한도

이 문서는 사이트가 사용하는 데이터 제공처의 성격, 호출 한도, 이용 조건을 정리한 것입니다.
약관과 요금제는 자주 바뀌므로 **운영 전에 각 제공처의 최신 약관을 직접 확인하세요.**
아래에서 "확인 필요"로 표시한 항목은 이 문서 작성 시점에 원문으로 검증하지 못한 내용입니다.

## 사이트의 데이터 사용 원칙

1. **출처 표시**: 화면의 수치, 표, 브리핑 문장마다 제공처와 기준 시각을 함께 보여 줍니다.
2. **추정 금지**: 제공처가 주지 않는 값(예: 커버드콜 옵션 행사가, 분배금 구성 비율, 경제지표 컨센서스)은 "미제공"으로 표시합니다.
3. **과거 데이터 표시 방식**: 최신 조회에 실패하면 저장된 데이터에 "최신 조회 실패" 경고와 수집 시각을 붙입니다.
4. **캐시와 재사용**: 시세, 봉, 배당, 프로필, 뉴스, 일정은 SQLite에 저장해 재사용합니다. 브리핑은 저장된 자료로만 생성합니다.
5. **장애 격리**: 제공처별 서킷 브레이커가 동작하고, 실패는 `job_runs`와 `provider_calls`에 기록됩니다. 데이터 상태 페이지에서 확인할 수 있습니다.

## 실시간·지연 표시 기준

- 시세의 "실시간/지연" 구분은 **제공처가 밝힌 값**(Yahoo `exchangeDataDelayedBy`, `quoteSourceName`)을 그대로 씁니다. 값이 없으면 "지연 여부 미확인(지연 데이터로 간주)"으로 표시합니다.
- 제공처가 실시간이어도 사이트가 데이터를 받은 시각(데이터 갱신 시각)은 따로 표시합니다. 정규장 중에는 워커가 15분마다 갱신하고, 상세 화면은 조회 시점 기준 60초보다 오래된 시세를 다시 받아옵니다.
