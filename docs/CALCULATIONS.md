# 계산 정의서

이 사이트의 모든 숫자가 어떻게 계산되는지 한곳에 적은 문서입니다. 코드의 주석과 같은 내용이며, 기준값(golden) 테스트가 이 정의를 지키는지 확인합니다.
계산 방식이 바뀌면 `src/lib/sim/repro.ts` 의 `ENGINE_VERSION` 을 올립니다. 저장한 결과에는 그때의 버전이 남아, 다른 버전으로 계산한 결과라는 것을 전략 화면에서 알려 줍니다.

> 모든 결과는 과거 데이터와 사용자가 고른 가정에 따른 계산입니다. 예측이나 수익 보장이 아닙니다.

---

## 1. 공통 원칙

| 항목 | 규칙 |
|---|---|
| 데이터 | 실제 수집한 일봉(분할 반영 종가)과 실제 분배금 기록만 씁니다. 없는 값을 0이나 직전 값으로 채우지 않고 "데이터 미제공" 또는 "계산 불가 (이유)"로 표시합니다. |
| 계산 불가 | 0 대신 `null` 을 돌려주고 화면에 이유를 적습니다 (예: "수익률 12개 — 20개 이상 필요", "낙폭 0"). |
| 부동소수점 | 계산 중에는 반올림하지 않습니다 (배정밀도). 반올림은 화면 표시 때만 합니다 (금액 소수 2자리, 비율 1~2자리). 표준편차가 부동소수점 오차 수준(1e−12 이하)이면 0으로 보고 비율 지표를 계산하지 않습니다 (`isNegligible`). |
| 시점 | 어떤 날의 값은 그날까지의 데이터로만 계산합니다. 예외는 일목균형표 후행스팬(표시 전용)뿐입니다. |
| 연환산 | 일간 → 평균 × 252, 표준편차 × √252. 월간 → × 12, × √12. 1년 미만 기간의 CAGR 은 연환산하지 않습니다. |
| 무위험 수익률 | 연 % 를 일간으로 나눠(÷ 252) 뺍니다. 백테스트는 기간 평균 13주 국채금리(^IRX) 또는 직접 입력, 지표 전략은 0%. |

## 2. 총수익 지수 (`trIndex`, `src/lib/sim/series.ts`)

사이트 전체에서 쓰는 단 하나의 총수익률 정의입니다. 백테스트, 내 자산 성과, 미래 시뮬레이터의 월말 총수익, 위험 예산, 스트레스 테스트 베타가 모두 이 함수를 씁니다.

- 첫날 값 = 1. i번째 값 = 직전 값 × (종가ᵢ + 그 사이 배당락 분배금) ÷ 종가ᵢ₋₁
- '그 사이'는 직전 거래일 다음 날부터 오늘(포함)까지입니다. 배당락일에 가격 기록이 없어도(휴장·누락) 다음 거래일에 반영해 빠뜨리지 않습니다.
- 분배금은 배당락일 종가로 재투자했다고 보며, 세금과 거래 비용은 넣지 않습니다. 세금과 비용은 각 엔진이 따로 반영합니다.
- 가격이 0 이하이거나 숫자가 아니면 그 구간은 직전 값을 유지합니다. 없는 수익률을 만들어 내지 않습니다.
- 가격은 분할만 반영한 종가이고, 분배금은 따로 더합니다. 수정주가(adjclose)와 분배금을 함께 쓰지 않으므로 이중 계산이 없습니다.

## 3. 주식분할 (`src/lib/portfolio/splits.ts`)

- 일봉과 분배금은 분할을 반영한 값(현재 주식 수 기준)입니다. 분할 기록은 시계열의 `splits [{date, ratio}]` 에 들어 있고, `date` 는 분할을 반영한 첫 거래일입니다.
- 거래일 이후 분할의 누적 비율 = 그 거래일보다 뒤에 있는 분할 비율의 곱입니다 (`splitFactorAfter`).
- 의심 거래는 다음 두 조건을 모두 만족하는 거래입니다.
  - 입력 가격이 '분할 반영 종가 × 누적 비율'과 ±20% 안에서 맞습니다.
  - 입력 가격이 분할 반영 종가와는 ±30% 넘게 다릅니다.
- 사용자가 확인하면 수량 × 비율, 가격 ÷ 비율로 바꿉니다. 거래 금액은 그대로이고, 메모에 표시를 남깁니다. 자동으로 고치지는 않습니다.

## 4. 내 자산 회계 (`src/lib/portfolio/ledger.ts`)

- **거래 종류**: 매수, 매도, 입금, 출금, 분배금 수령, 분배금 재투자, 기초 보유.
- **같은 날 처리 순서**: 날짜순, 같은 날이면 입력한 순서(생성 시각)대로 처리합니다.
- **평균 단가**: 이동평균입니다. 매수 원가에 수수료를 더합니다.
- **실현 손익**: 매도 금액 − 수수료 − 평균 단가 × 수량.
- **매도 제한**: 보유 수량보다 많은 매도는 반영하지 않고 경고합니다.
- **현금**: 다음 항목을 모두 더한 값입니다.
  - 입금 − 출금
  - 매도 대금 − 매수 대금
  - 세후 분배금
  - − 수수료
  - (분배금 재투자는 세후 금액 − 재투자 매수 금액)
- **원금(순납입)**: 입금 − 출금 + 기초 보유 평가액. 외부 입출금은 수익률에 섞지 않습니다.
- **시간가중수익률(TWR)**: 매일 (오늘 평가액 − 오늘 외부 입출금) ÷ 어제 평가액을 이어 곱한 값입니다. 입출금은 그날 종가 전에 들어온 것으로 봅니다.
- **금액가중수익률(XIRR)**: 입금(−), 출금(+), 기초 보유(−)와 기준일 평가액(+)으로 구한 연환산 내부수익률입니다.
- **검증**: 다음 식이 맞는지 화면에 함께 보여 줍니다.
  - 총손익 = 미실현 + 실현 + 세후 분배금
  - 총자산 = 평가금액 + 현금
- **테스트**:
  - 손으로 계산한 기준값
  - 무작위 거래 300세트 속성 테스트: 현금 보존, 수량 비음수, 총손익 항등식 (`tests/ledger-golden.test.ts`)

## 5. 기술적 지표 (`src/lib/ta.ts`, 목록은 `src/lib/ta-registry.ts`)

차트와 지표 전략 백테스트가 같은 함수를 씁니다.

### 공통 규칙

- **출력 형태**: 입력과 같은 길이의 배열을 돌려줍니다. 계산할 수 없는 자리는 `null` 입니다.
- **누락**: 다음 경우는 그 자리를 '누락'으로 봅니다.
  - 값이 숫자가 아님
  - 가격 ≤ 0
  - 고가 < 저가
  - 종가가 고가·저가 밖
- **창 지표** (SMA·WMA·볼린저·돈치안·CCI·CMF 등): 창 안에 누락이 있으면 `null` 입니다.
- **재귀 지표** (EMA·RMA·RSI·ATR·ADX·OBV·A/D 등): 누락 자리에서 상태를 버리고 다음 유효값부터 초기화를 다시 합니다.
- **분모 0**: 고가 = 저가, 거래량 0, 변화 없음이면 `null` 입니다.
- **범위가 정해진 오실레이터** (RSI, 스토캐스틱, %R, MFI): 부동소수점 오차(1e−9 이내)만 범위 안으로 맞추고, 그보다 크게 벗어난 값은 고치지 않습니다.
- **차트 데이터 정리** (`cleanBars`): 시각순 정렬, 같은 시각은 마지막 것만, 비정상 봉은 누락으로 바꿉니다. 고친 내용은 차트 아래에 표시합니다.

### 지표별 정의 ("첫 값"은 0부터 센 봉 위치)

| 묶음 | 지표 | 정의 | 첫 값 |
|---|---|---|---|
| 추세 | SMA(n) | 최근 n개 종가 평균 | n−1 |
| | EMA(n) | α = 2/(n+1), 첫 값 = 처음 n개 SMA | n−1 |
| | WMA(n) | 가중치 1..n (최근이 n) | n−1 |
| | VWMA(n) | Σ(종가×거래량) ÷ Σ거래량 | n−1 |
| | 일목균형표 | 전환 = (9봉 최고+최저)/2, 기준 = 26봉 중간값, 선행A = (전환+기준)/2 를 26봉 뒤에 표시, 선행B = 52봉 중간값을 26봉 뒤에 표시 (둘 다 26봉 전까지의 데이터), **후행스팬 = 26봉 뒤 종가를 지금 자리에 표시 (미래 값이라 표시 전용 — 전략 조건에 쓰지 않음)** | — |
| | Supertrend(n,m) | 기본 밴드 = (고+저)/2 ± m×ATR. 최종 밴드는 이전 값보다 불리하게 움직이지 않음. 하락 추세에서 종가가 최종 상단을 넘으면 상승 전환, 반대도 같음 (TradingView 와 같은 순서) | ATR 첫 값 |
| | ADX(n) | Wilder 원래 정의. TR·+DM·−DM 을 Wilder 평활 → +DI·−DI(첫 값 n) → DX → ADX = DX 의 Wilder 평활 | 2n−1 |
| 모멘텀 | RSI(n) | Wilder 평활 평균 상승 ÷ 평균 하락 = RS, RSI = 100 − 100/(1+RS). 평균 하락 0 → 100, 평균 상승 0 → 0, 둘 다 0 → null | n |
| | MACD(f,s,g) | EMA(f) − EMA(s), 시그널 = MACD 의 EMA(g) (MACD 첫 값부터 초기화), 히스토그램 = 차이 | s−1 (시그널 s+g−2) |
| | 스토캐스틱(n,k,d) | 원값 = 100 × (종가−n봉 최저)/(n봉 최고−최저), %K = SMA(원값,k), %D = SMA(%K,d) | n+k−2 |
| | 스토캐스틱 RSI | RSI 를 n봉 최고·최저로 0~100 정규화 → SMA | — |
| | ROC(n) / 모멘텀(n) | 100 × (종가/n봉 전 − 1) / 종가 − n봉 전 | n |
| | CCI(n) | (TP − SMA(TP)) ÷ (0.015 × 평균 절대 편차), TP = (고+저+종)/3 | n−1 |
| | Williams %R(n) | −100 × (n봉 최고 − 종가)/(최고 − 최저) | n−1 |
| | TRIX(n) | 100 × (EMA³ₜ / EMA³ₜ₋₁ − 1) | 3(n−1)+1 |
| 변동성 | ATR(n) | TR = max(고−저, \|고−전일 종가\|, \|저−전일 종가\|), Wilder 평활 | n−1 |
| | 역사적 변동성(n) | 로그수익률 n개 **표본** 표준편차 × √252 × 100 | n |
| | 볼린저(n,k) | 중간 = SMA(n), 상·하단 = 중간 ± k × **모집단** 표준편차. %B = (종가−하단)/(상단−하단), 밴드폭 = (상단−하단)/중간 | n−1 |
| | 켈트너(n, atrN, m) | 중간 = EMA(n), 상·하단 = 중간 ± m × ATR(atrN) | EMA·ATR 둘 다 있는 첫 봉 |
| | 돈치안(n) | n봉 최고가·최저가(현재 봉 포함). 돌파 신호는 '직전 봉까지'의 채널과 비교 | n−1 |
| 거래량 | OBV | 상승 봉 +거래량, 하락 봉 −거래량, 같으면 0. 누락 뒤 0부터 다시 | 0 |
| | MFI(n) | 100 − 100/(1 + 양의 자금흐름 합/음의 합). 음 합 0 → 100 | n |
| | CMF(n) | Σ(자금흐름 배수 × 거래량) ÷ Σ거래량, 배수 = ((종−저)−(고−종))/(고−저) | n−1 |
| | A/D 선 | 배수 × 거래량의 누적합 | 0 |
| | VWAP | 분봉: 거래일마다 0부터 누적하는 세션 VWAP. 일봉 이상: 20봉 이동 VWAP (TP 가중) | — |

- **기준값**: 손으로 계산하거나 교과서 예제와 맞춘 기준값으로 확인합니다.
- **속성 테스트**:
  - 미래 봉을 바꿔도 과거 값이 같은지 (미래 정보 없음)
  - NaN 이 섞인 입력에서 오류 없이 `null` 을 돌려주는지
  - 범위 지표가 범위 안에 있는지

## 6. 성과·위험 지표 (`src/lib/sim/metrics.ts`, `src/lib/sim/risk-metrics.ts`)

입력은 시간가중 가치 지수(추가 납입 효과 제외)이고, 일간 수익률 rₜ = Vₜ/Vₜ₋₁ − 1 입니다.

| 지표 | 정의 | 계산 안 하는 경우 |
|---|---|---|
| CAGR | (끝/처음)^(1/년수) − 1, 년수 = 달력일 ÷ 365.25 | 1년 미만 |
| 변동성 | 일간 표준편차(표본, n−1) × √252 | 수익률 20개 미만 |
| 샤프 | (평균 r × 252 − rf) ÷ (표준편차 × √252) | 수익률 60개 미만, 변동 없음 |
| 최대 낙폭 | min(Vₜ ÷ 그때까지 최고값 − 1) | — |
| 하방 변동성 | √(평균(min(r − MAR, 0)²)) × √252, 분모는 전체 관측 수, MAR = rf 일간 | 수익률 20개 미만 |
| 소르티노 | (평균 r × 252 − rf) ÷ 하방 변동성 | 하락이 한 번도 없음 |
| 칼마 | CAGR ÷ \|최대 낙폭\| | 낙폭 0, CAGR 없음 |
| 하루 VaR 95% | 과거 일간 수익률을 오름차순 정렬한 뒤 k = ⌈0.05·n⌉ 번째 값의 손실 (부동소수점 보정 −1e−9) | 수익률 40개 미만 |
| 하루 CVaR 95% | 하위 k개 수익률의 평균 손실 (항상 VaR 이상) | 같음 |
| 월간 VaR 95% | 완전한 달의 월 수익률 5% 분위수(선형 보간)의 손실 | 완전한 달 24개 미만 |
| 베타 | 공분산(r, b) ÷ 분산(b), 같은 날짜끼리 맞춘 일간 수익률 | 벤치마크 분산 0 |
| 젠센 알파 | (평균 r − rf) × 252 − 베타 × (평균 b − rf) × 252 | — |
| 추적 오차 | 표준편차(r − b) × √252 | — |
| 정보 비율 | 평균(r − b) × 252 ÷ 추적 오차 | 추적 오차 0 |
| 하락 기간 | 고점 아래에 머문 가장 긴 기간(달력일), 최대 낙폭 저점 → 이전 고점 회복까지 | 미회복이면 "미회복" |
| 최악의 달·분기·연도 | 처음·끝이 잘린 기간은 빼고 비교 (잘린 기간은 '부분' 표시) | — |
| 이동 창 | 252거래일 창을 5거래일마다: 수익률·변동성·샤프·최대 낙폭 | 데이터 252일 미만 |

- **트레이드 통계** (지표 전략):
  - 승률 = 이익 거래 ÷ 청산 거래
  - 평균 이익·평균 손실 (거래 수익률 %)
  - 수익 팩터 = 총이익 ÷ \|총손실\|
  - 기대값 = 거래당 평균 수익률
  - 평균 보유 봉·달력일
  - 노출 비율 = 보유한 봉 ÷ 전체 봉
  - 회전율 = 매매 금액 합 ÷ 평균 평가액 ÷ 년수
  - 거래 내역에는 거래마다 수수료·슬리피지 비용이 표시됩니다.
- **기준값 테스트**: 손으로 계산한 수열로 확인합니다 (`tests/metrics-golden.test.ts`). 다음 두 버그를 이 테스트로 찾아 고쳤습니다.
  - 일정한 수익률에서 샤프가 2.4e16 으로 나오던 문제
  - VaR 꼬리 개수가 6이 되던 문제: (1−0.95)×100 = 5.000000000000004

## 7. 포트폴리오 백테스트 (`src/lib/sim/backtest.ts`)

- **계산 달력**: 모든 종목에 종가가 있는 날만 씁니다. 가격이 없는 날을 채우지 않습니다.
- **납입**: 월초 첫 거래일 또는 월말 마지막 거래일 종가로 목표 비중만큼 삽니다.
- **리밸런싱**: 새 기간의 첫 거래일 종가에 합니다.
- **비용**: 거래 비용은 사고판 금액에 부과합니다. 분배금은 원천징수 후 배당락일 종가로 재투자하거나 현금으로 둡니다(이자 0).
- **양도세** (선택): 1~12월 손익을 합산한 뒤 250만 원을 공제하고 22%를 매깁니다.
- **수익 지표**: 시간가중 지수로 계산합니다. IRR 은 금액가중입니다.
- **재현 정보**:
  - 데이터 코드 = 계산 기간 안 날짜·종가·분배금의 FNV-1a 해시
  - 설정 코드 = 조건의 해시
  - 결과를 저장할 때 계산 방식 버전과 데이터 기간을 함께 남깁니다.

## 8. 지표 전략 백테스트 (`src/lib/sim/strategy.ts`, 화면 `/backtest/strategy`)

### 시점 규칙 (미래 정보 차단)

- 신호는 i번째 봉의 종가가 확정된 뒤 i번째까지의 데이터로만 계산합니다.
- 체결은 다음 봉에서 합니다: 다음 날 시가(기본) 또는 다음 날 종가. 신호가 난 종가에 미리 체결하지 않습니다.
- 체결 가격이 없는 봉이면 다음 유효한 봉까지 미룹니다. 마지막 봉의 신호는 체결되지 않습니다.
- 손절·익절은 종가 기준으로 판단하고 다음 봉에 체결합니다. 장중 가격으로 손절됐다고 가정하지 않습니다.
- 최대 보유는 봉 수로 셉니다.
- 배당락일에는 전날 종가 기준 보유 수량에만 분배금을 줍니다.

### 거래 가정

- 자금 전부로 사고 전부 팝니다 (소수점 수량). 쉬는 현금의 이자는 0입니다.
- 수수료 = 거래 금액 × 수수료율.
- 슬리피지는 살 때 가격 × (1 + bp), 팔 때 × (1 − bp) 입니다.
- 비교 대상 '매수 후 보유'도 같은 비용과 같은 분배금 처리를 씁니다.
- 지표 준비 구간으로 시작일 앞 최대 400봉을 더 불러오되, 성과는 시작일부터 셉니다.

### 과최적화 점검

| 점검 | 방법 |
|---|---|
| 학습·평가 구간 | 기간을 비율로 나눠 따로 성과를 냅니다. 같은 전략을 이어서 운용하고 구간만 나눠 셉니다. |
| 파라미터 민감도 | 최대 8×8 격자. 최고 칸과 바로 옆 칸 평균·최저를 비교하고, 최고 칸의 평가 구간 성과를 함께 보여 줍니다. |
| 워크포워드 | 학습 창(기본 3년)에서 샤프가 가장 높은 값을 고르고 다음 평가 창(1년)에 적용한 결과만 이어 붙입니다. 각 후보는 처음부터 끝까지 이어서 운용한 결과를 쓰고, 고를 때는 학습 창 끝까지의 성과만 봅니다. |
| 시장 국면 | 연도별 '매수 후 보유' 수익률로 상승(>+10%), 하락(<−10%), 횡보로 나누고, 국면별 평균을 비교합니다. 1년 전체가 있는 연도만 씁니다. |
| 미래 정보 검사 | 화면에서 실행할 때마다 학습·평가 분할 지점(기본 70%) 뒤의 시가·고가·저가·종가를 크게 바꿔 다시 계산하고, 그 전의 평가금액과 끝난 거래가 같은지 확인합니다. |

생존 편향: 지원 종목은 지금 상장된 종목이며, 상장 폐지된 종목은 들어 있지 않습니다. 화면에 이 한계를 적어 두었습니다.

## 9. 레버리지 ETF 점검 (`src/lib/leverage.ts`)

- **실제와 배수 기대의 차이**: 기간마다 실제 수익률과 '기준 ETF 수익률 × 배수'를 비교합니다.
- **횡보장 vs 추세장**: 63거래일 구간을 21거래일 간격으로 나눕니다.
  - 기준 ETF 가 ±3% 안이면 횡보, +10% 초과면 상승, −10% 미만이면 하락으로 봅니다.
  - 국면마다 (실제 − 기준 × 배수)의 평균을 냅니다.
- **필요 회복률**: 손실 L% 를 회복하려면 L ÷ (100 − L) × 100 % 가 오릅니다.

## 10. 미래 시뮬레이터 (`src/lib/sim/future.ts`)

- **시나리오**: 가격 수익률 = 총수익률 − 분배금 수익률 ('총수익률 고정' 가정). 분배금 = 평가금액 × 분배금 수익률 × 과거 실제 지급 월 비중.
- **몬테카를로**:
  - 모든 종목에 공통인 완전한 월의 실제 수익률을 6개월 블록으로 다시 뽑습니다.
  - 시드가 같으면 결과가 같습니다.
  - 공통 데이터가 36개월 미만이면 실행하지 않습니다.
- **가정 민감도**: 한 번에 가정 하나만 바꾸고 나머지는 그대로 둔 결과를 영향이 큰 순으로 보여 줍니다.
  - 가격 수익률 ±2%p
  - 분배금 −30%
  - 분배금 세율 30%
  - 연 비용 +0.5%p
  - 거래 비용 +0.5%p
  - 시작 직후 −30% 급락 (초기 투자금 × 0.7)
  - 원/달러 ±10% (달러 결과는 그대로, 원화 환산만 바뀜)

## 11. 재현성 (`src/lib/sim/repro.ts`)

- `ENGINE_VERSION`: 계산 방식 버전입니다. 저장한 결과(백테스트, 지표 전략, 미래 시뮬레이터)에 함께 남습니다.
- 저장하는 정보:
  - 데이터 기간(처음 ~ 끝)
  - 데이터 코드 (FNV-1a, 날짜·OHLCV)
  - 설정 코드
  - 주요 가정 (체결 방식, 수수료, 슬리피지, 세율)
- 데이터가 새로 수집되거나 정정되면 코드와 결과가 달라질 수 있습니다. 같은 데이터 코드와 같은 설정이면 같은 결과가 나오는지 단위 테스트로 확인합니다.

### 공포·탐욕 지수 (`src/lib/providers/cnn.ts`)
- 구간: 0~25 극단적 공포, 25~45 공포, 45~55 중립, 55~75 탐욕, 75~100 극단적 탐욕 (경계값은 위 구간). CNN 화면 기준이며, 실제 기록(2024-10-14~2026-10-14, 501거래일)의 판정과 점수로 확인했습니다 (극단적 공포 최대 24.8, 공포 25.1~44.9, 중립 45.2~55.0, 탐욕 55.0~74.7, 극단적 탐욕 75.1 이상 — 구간과 CNN 판정이 다른 날 0일). 판정은 CNN 이 준 값을 먼저 쓰고, 없을 때만 이 구간으로 정합니다 (그렇다고 표시).
- 일별 기록: UTC 0시 점만 씁니다(그날의 마지막 값). 끝에 붙는 '지금 시각' 점은 일별 기록이 아닙니다. 수집 기준일 뒤 날짜(아직 진행 중인 날)는 저장하지 않습니다.
- 장 마감 뒤에도 일부 구성 지표가 늦게 갱신되므로, 수집할 때마다 최근 약 1년을 다시 받아 같은 날짜를 덮어씁니다 (처음에는 약 2년).
- 검사: 지수 값이 0~100 숫자가 아니거나 기준 시각이 없으면 오류로 보고 저장하지 않습니다. 일별 점 중 잘못된 값이 5% 를 넘으면 오류, 그 이하면 빼고 개수를 남깁니다. 없는 구성 지표는 '데이터 미제공'으로 두고 다른 값으로 채우지 않습니다.
- 각 지표를 점수로 바꾸는 자세한 방식은 CNN 이 공개하지 않아 이 사이트에서 검증할 수 없습니다.

### 검증 규칙
- **분모 0·값 이상**: 분모가 0 이하이거나 숫자가 아니면 비율은 `null`입니다. 다른 지표 값으로 채우지 않습니다.
- **설문 합계**: 세 비율은 각각 0~100 이어야 하고 합계는 100 ± 0.5 (반올림 오차) 여야 합니다. 벗어난 주는 계산에서 빼고 화면에 따로 알립니다.
- **파일·응답 검사**:
  - 공매도 거래량 파일은 머리글이 맞아야 읽고, 공매도 > 전체·음수·숫자 아님인 행은 버립니다.
  - 옵션 체인은 '--' 를 거래 없음(0)으로 봅니다. 숫자 형식이 깨진 행이 5% 를 넘으면 오류로 봅니다 (전부 깨진 경우 포함).
  - 일부 행만 받은 체인은 저장하지 않습니다.
- **13F 정정 공시**:
  - 원 공시 또는 가장 최근 '전체 대체'(RESTATEMENT) 정정을 기준으로 삼고, 그 뒤 '추가 보고'(NEW HOLDINGS) 정정의 행을 더합니다.
  - 종류를 알 수 없는 정정은 반영하지 않고 표시만 합니다.
  - 2023-01-03 이전 제출분은 가치를 천 달러 단위에서 달러로 바꿉니다. 채권 원금(PRN) 행은 뺍니다.
- **13F 가격 대조**:
  - 신고 가치 ÷ 주식 수가 보고 기간 말 실제 종가와 10% 넘게 다르면 '가격 대조 불일치'로 표시합니다. CUSIP 매핑이나 단위 오류를 잡기 위한 검사입니다.
  - CUSIP 은 SEC 13(f) 목록과 실제 13F 의 가치 ÷ 수량 = 종가로 확인한 것만 씁니다 (SPXL 은 확인하지 못해 제외).
- **목록에서 빠짐**: 직전 공시에 있던 종목이 이번 공시에 없는 상태입니다. 직전 공시 자료가 없으면 비교하지 않습니다.
- **오래된 자료 경고**: 마지막 날짜부터 지난 일수가 아래를 넘으면 경고합니다.

  | 자료 | 기준 |
  |---|---|
  | 설문 | 14일 |
  | 공매도 잔고 | 40일 |
  | 공매도 거래량·옵션 | 7일 |
  | 13F 보고 기간 말 | 200일 |
  | 공포·탐욕 지수 (CNN 기준 시각) | 5일 |
- **중복 방지**: 모든 표는 (종목, 날짜) 같은 기본키로 덮어씁니다. 13F 는 제출 번호(accession) 단위로 지우고 다시 넣습니다.
